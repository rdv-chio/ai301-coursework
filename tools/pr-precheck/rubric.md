## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| plan_fidelity | Unified diff and description claims read against plan scope & deviations | The diff implements the planned changes without introducing unannounced scope creep, unrelated refactors, or new configuration flags not in the plan. Any omitted planned item or scope modification must be explicitly documented in plan deviations and stated in the description. The description must not claim changes the diff does not contain. | required |
| decisive_test_evidence | Test evidence section read against plan's test plan and repro steps | The test evidence shows the observable before/after verification on the actual failing code path isolated in the repro/plan (not solely on unchanged controls or generic test passes). Required repo checks (e.g., test suite, linters) must show visible execution results. | required |
| clean_reviewable_diff | Unified diff hunks and commit history | The diff contains only the purposeful changes needed for the fix. It is clean of debris: no leftover debug print statements, no commented-out experimental code blocks, no dead functions, and no unrelated indentation/formatting churn hunks. | required |
| standards_compliance | PR description read against repo_facts (PR template, checklists, and AI policy) | All required PR template sections and checklists are preserved and filled with substantive content (not left blank or stripped). If repository policy mandates explicit AI-use disclosure, an explicit disclosure statement must be present. | required |

## Verdict rule

<!-- State how the grades above combine into accept or reject, and how

Accept if every required check passes. Reject if any required check fails or is unclear. Preferred checks never change the verdict.
